# 🛡️ AI Image & Video Forensics

An interactive tool that checks whether an image or video was generated by AI. A Vision Transformer (ViT) classifier judges each image or video frame, and Error Level Analysis (ELA) produces a heatmap of regions that look edited.

## 🚀 Features

### 🖼️ Image forensics
* **AI or camera?** The `Organika/sdxl-detector` model (Hugging Face) classifies an image as `artificial` or `human` (camera-original), with a confidence score.
* **ELA heatmap:** the image is re-saved as JPEG and compared with the original. Edited or generated regions recompress differently and show up brighter.

### 🎥 Video forensics ("paranoid mode")
* **Frame sampling:** every 15th frame is checked by the same model.
* **Whole-video verdict:** if more than 15% of the sampled frames are confidently AI (above 70%), the video is flagged.
* **Compression warning:** small, heavily compressed files (WhatsApp, Facebook) often lose the pixel-level "fingerprints" that AI leaves behind. The app warns when a result may be a false negative, and explains why.

## ⚙️ Tech stack
* **UI:** Streamlit
* **Model:** Hugging Face Transformers `pipeline` (image classification), PyTorch
* **Vision:** OpenCV, Pillow

## 🛠️ Run it locally
```bash
git clone https://github.com/Akhil-7770/ai-image-and-video-detection.git
cd ai-image-and-video-detection
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
The model (about 350 MB) downloads automatically the first time you analyse an image.

## ⚠️ Limitations
* A detector trained on one family of generators (here, SDXL-style images) is less reliable on images from newer or different generators.
* Video results depend heavily on compression. A low "fake" score is not proof that a video is real.
* ELA highlights *where* an image recompresses unevenly. It doesn't prove manipulation on its own.
